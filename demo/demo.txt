The Gradio demonstration for this project is included in the Evaluation & Deployment notebook.

To run the demo:

Open the Evaluation & Deployment notebook.
Run all the cells from the beginning.
The last section of the notebook will launch the Gradio interface.
Upload a dog skin image to receive the predicted disease class.

If you do not wish to run the notebook locally, you can also access the demo using the link below:

Demo Link:
 https://344ba2dd3d43a966e5.gradio.live/


Note: If the demo link is unavailable or has expired, simply run the Evaluation & Deployment notebook in Google Colab to launch a new Gradio session.
