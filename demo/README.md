# Demo

This project includes a **Gradio-based demonstration** for predicting dog skin diseases using the trained deep learning model.

## Running the Demo

The demo is included in the **Evaluation & Deployment** notebook.

To launch the demo:

1. Open the **Evaluation & Deployment** notebook.
2. Run all the cells from the beginning.
3. The Gradio interface will be created in the final section of the notebook.
4. Upload a dog skin image to receive the predicted disease class.
