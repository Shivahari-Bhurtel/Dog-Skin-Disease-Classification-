# Notebooks

This folder contains the Jupyter notebooks developed during the Dog Skin Disease Classification project.

## Notebook Description

### `dataset_preparation_eda.ipynb`

* Dataset loading and organization
* Exploratory Data Analysis (EDA)
* Data cleaning and preprocessing
* Duplicate and corrupt image detection
* Feature engineering
* Dataset preparation for model training

### `cnn_model.ipynb`

* CNN model implementation
* Model training and validation
* Performance evaluation

### `efficientnet_b0.ipynb`

* EfficientNet-B0 model implementation
* Transfer learning and fine-tuning
* Model training and validation
* Performance evaluation

### `evaluation_deployment.ipynb`

* Model evaluation using performance metrics
* Confusion matrix and classification report
* Gradio-based deployment for predicting dog skin diseases from uploaded images

## Note

Run the notebooks in the above order to reproduce the complete workflow, from dataset preparation to model evaluation and deployment.
